# HakiOS-x86

This directory contains prebuilt binaries:
- `mach.development.x86_64` — XNU kernel (development build)
- `mach.release.x86_64` — XNU kernel (release build)
- `mach.debug.x86_64` — XNU kernel (debug build)
- `xnuloader.efi` — UEFI boot loader
- `libSystem.dylib` — System library

These are built from source in this repository. See the main README
for build instructions.
